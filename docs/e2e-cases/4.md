# End-to-end cases for #4 — Docker Compose for PostgreSQL and Redis with environment config

Derived from the acceptance criteria of issue #4 (Covers: R8, D1). No case here
was taken from the implementation.

This story describes infrastructure, so every case is a probe: none of the three
people in the system (vendor, admin, shopper) appears in any criterion.

### 4-1

- Actor: none (probe)
- Covers: criterion 2 of #4
- Precondition: `.env.example`, `src/shared/config.ts`
- Given: `.env.example` copied to `.env`
- When: the app loads config
- Then: `DATABASE_URL`, `REDIS_URL`, `PORT`, `UPLOAD_DIR` are parsed with zod
- Measure: none

### 4-2

- Actor: none (probe)
- Covers: criterion 2 of #4
- Precondition: `src/shared/config.ts`
- Given: an `.env` with `DATABASE_URL` removed
- When: the app loads config
- Then: the missing value fails fast with a clear message (the process exits
  non-zero on load rather than starting, and the message names `DATABASE_URL`)
- Measure: none

### 4-3

- Actor: none (probe)
- Covers: criterion 2 of #4
- Precondition: `src/shared/config.ts`
- Given: an `.env` with `PORT` set to a malformed value (`not-a-number`)
- When: the app loads config
- Then: the malformed value fails fast with a clear message (the process exits
  non-zero on load rather than starting, and the message names `PORT`)
- Measure: none

### 4-4

- Actor: none (probe)
- Covers: criterion 4 of #4
- Precondition: `docker-compose.yml`, `tools` profile
- Given: `pgadmin`/`redis-commander`
- When: `docker compose up -d --wait` runs without the profile
- Then: they do not start (neither container is running)
- Measure: none

### 4-5

- Actor: none (probe)
- Covers: criterion 1 of #4
- Precondition: `docker-compose.yml`
- Given: a clean checkout
- When: `docker compose up -d --wait` runs
- Then: `postgres:16-alpine` and `redis:7-alpine` are healthy on 5432 and 6379,
  and Postgres has the `btree_gist` extension available
  (`SELECT 1 FROM pg_available_extensions WHERE name = 'btree_gist'` returns a row)
- Measure: none

### 4-7

- Actor: none (probe)
- Covers: criterion 3 of #4
- Precondition: `.github/workflows/ci.yml`, `ci` job `services:`
- Given: CI
- When: the `ci` job runs
- Then: Postgres and Redis service containers are available to integration tests
- Measure: none
